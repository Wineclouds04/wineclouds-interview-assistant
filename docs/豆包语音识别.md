# 豆包语音识别 (ASR)

除本地 **Whisper** 外，本助手支持使用 **火山引擎豆包流式语音识别（小时版）** 作为 STT 引擎。豆包 ASR 需在火山引擎控制台开通，并在 `backend/config.json` 中配置；设置页也可以直接填写这些字段。

> **不要混用密钥：** 火山方舟（Ark）模型 API Key 通常以 `ark-` 开头，只能用于方舟模型推理，不能填到豆包 ASR 的 API Key 字段。本项目当前豆包客户端使用语音服务的旧版 WebSocket 协议，需要语音控制台生成的 UUID API Key，或同一语音应用的 App ID + Access Token。混用时会在握手阶段收到 `401 Unauthorized`。

## 1. 开通与获取密钥

### 新版控制台（推荐）

1. 打开 [火山引擎 - 豆包语音 - 新版控制台](https://console.volcengine.com/speech/new/setting/apikeys) ，按指引开通「豆包流式语音识别模型 1.0 小时版」。
2. 在 **API Key 管理** 页面创建 API Key，复制生成的 **API Key**（UUID 格式）。
3. 新版控制台鉴权只需要一个 `X-Api-Key` header，无需 App ID 和 Access Token。

### 旧版控制台

1. 打开 [火山引擎 - 豆包语音识别](https://www.volcengine.com/docs/6561/1354869) 文档，按指引开通。
2. 在控制台创建应用，获取：
   - **App ID**（用于请求头 `X-Api-App-Key`）
   - **Access Token**（用于 `X-Api-Access-Key`）
3. 确认该应用已开通对应资源 ID（小时版或并发版）。

## 2. 配置文件

在 `backend/config.json` 中填写（仅当 `stt_provider` 为 `"doubao"` 时生效）：

### 新版控制台（推荐）

```json
{
  "stt_provider": "doubao",
  "doubao_stt_api_key": "你的API Key",
  "doubao_stt_resource_id": "volc.bigasr.sauc.duration",
  "doubao_stt_boosting_table_id": ""
}
```

- `doubao_stt_api_key`：新版控制台生成的 API Key（UUID 格式）。**填了此项后，App ID 和 Access Token 将被忽略**。
- `doubao_stt_resource_id`：
  - 豆包流式语音识别模型 1.0 小时版：`volc.bigasr.sauc.duration`
  - 豆包流式语音识别模型 1.0 并发版：`volc.bigasr.sauc.concurrent`
  - 豆包流式语音识别模型 2.0 小时版：`volc.seedasr.sauc.duration`
  - 豆包流式语音识别模型 2.0 并发版：`volc.seedasr.sauc.concurrent`

### 旧版控制台

```json
{
  "stt_provider": "doubao",
  "doubao_stt_app_id": "你的App ID",
  "doubao_stt_access_token": "你的Access Token",
  "doubao_stt_resource_id": "volc.seedasr.sauc.duration",
  "doubao_stt_boosting_table_id": ""
}
```

- `doubao_stt_boosting_table_id`：可选。若在控制台创建了热词表，将热词表 ID 填在此处，可提升专业术语识别率。

## 3. 热词表（可选）

项目提供 **[docs/stt/doubao_hotwords_面试技术词表.txt](./stt/doubao_hotwords_面试技术词表.txt)**，内含常见技术词（中英文）。上传为热词表后可减少专有名词识别错误。说明摘要见 [docs/stt/README.md](./stt/README.md)。

**格式要求**：每行一个词，**不要权重、不要特殊符号**；仅字母/数字/中文，UTF-8 编码。

**上传步骤**：

1. 打开 [火山引擎 - 豆包语音 - 自学习平台 - 热词管理](https://console.volcengine.com/speech/hotword)。
2. 点击「添加热词文件」，输入名称（如：面试技术词表）。
3. 上传上述 `docs/stt/` 下的词表文件，或复制其内容粘贴。
4. 提交后，在列表中复制该词表对应的 **热词 ID**。
5. 在 `config.json` 中设置 `doubao_stt_boosting_table_id` 为上述 ID。

不填 `doubao_stt_boosting_table_id` 则不使用热词表，ASR 仍可正常使用。

## 4. 界面操作

在 **设置 → 语音识别引擎** 中选择 **「豆包（API）」** 即可切换，然后填写语音控制台的 API Key，或填写旧版 App ID + Access Token。保存后点击「测试连接」。如果仍返回 401，请先核对密钥类型、语音服务开通状态和 Resource ID 是否属于同一版本。
