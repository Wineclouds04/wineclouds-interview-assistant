# 配置说明

配置文件位于 `backend/config.json`。首次运行前需从模板复制：

```bash
cp backend/config.example.json backend/config.json
```

> ⚠️ `config.json` 包含 API Key 等敏感信息，已加入 `.gitignore`，**不会被提交到 Git**。仓库中只有 `config.example.json` 模板。

## 完整字段说明

```jsonc
{
  // ── 大模型配置 ────────────────────────────────────
  "models": [ { "name", "api_base_url", "api_key", "model", "supports_think", "supports_vision" } ],
  "active_model": 0,
  "temperature": 0.7,
  "max_tokens": 4096,
  "think_mode": false,

  // ── 语音识别 ──────────────────────────────────────
  "stt_provider": "whisper",        // "whisper" | "doubao" | "generic"
  "whisper_model": "base",          // tiny/base/small/medium/large-v3
  "whisper_language": "zh",
  // 豆包 ASR（仅当 stt_provider 为 doubao 时使用，见 docs/豆包语音识别.md）
  "doubao_stt_app_id": "",
  "doubao_stt_access_token": "",
  "doubao_stt_resource_id": "volc.seedasr.sauc.duration",
  "doubao_stt_boosting_table_id": "",
  // 通用 ASR（仅当 stt_provider 为 generic 时使用）
  "generic_stt_api_base_url": "https://api.example.com/v1",
  "generic_stt_api_key": "",
  "generic_stt_model": "whisper-1",
  // 候选人麦克风 ASR：可选辅助链路，只用于追问上下文，不触发自动答题
  "candidate_asr_enabled": false,
  "candidate_stt_provider": "whisper",
  "candidate_whisper_model": "",
  "candidate_whisper_language": "",
  "candidate_remote_stt_enabled": false, // UI 中选择豆包/通用 ASR 时会自动写为 true
  "candidate_context_enabled": true,
  "candidate_context_wait_ms": 200,
  "candidate_context_max_chars": 900,
  "candidate_context_min_chars": 6,
  "candidate_streaming_asr_enabled": true,
  "candidate_streaming_asr_interval_ms": 1500,

  // ── 学习配置 ──────────────────────────────────────
  "position": "后端开发",
  "language": "Python",

  // ── 语音检测 (VAD) ───────────────────────────────
  "auto_detect": true,
  "silence_threshold": 0.01,
  "silence_duration": 2.0
}
```

- **实时辅助语音链路**：
  - `stt_provider` 是主链路，识别「会议音频 / 面试官声音」。识别到问题后会触发自动答题。
  - `candidate_asr_enabled` 是辅助链路开关，读取「我的麦克风」。这一路只记录候选人真实回答，服务下一轮问题上下文；不会触发自动答题。
  - `candidate_stt_provider=whisper` 表示候选人麦克风本地识别，不产生远程 ASR 成本；选择 `doubao` 或 `generic` 表示候选人麦克风也走云端，会产生额外 ASR 调用成本。
  - `candidate_context_enabled=true` 时，下一轮问题会携带上一轮候选人真实口述作为背景。若系统判断为追问，真实口述强优先；若不是追问，只作为可忽略背景，避免把无关问题强行关联。
  - `candidate_context_enabled=false` 时，即使麦克风有转写，也按旧逻辑只参考助手上一轮建议答案。
  - `candidate_streaming_asr_enabled=true` 时，本地 Whisper 会“边听边写”：先把已识别到的内容写入上下文，面试官提下一题时可直接使用已有内容；停顿后再用完整结果覆盖。云端候选人 ASR 不做预转写，避免反复调用计费。
  - `candidate_context_wait_ms` 是兜底等待。边听边写已经会提前写入上下文；这个只是在你刚说完、最后一句还没写进去时，下一题生成前最多再等一下。设为 0 表示不等。
  - `candidate_remote_stt_enabled` 是后端成本保护字段。设置页会在选择候选人云端 ASR 时自动处理，通常不需要手写。
- **语音识别配置**：通用 ASR 需要填写兼容 OpenAI `/audio/transcriptions` 的 Base URL、API Key 和模型名；豆包配置见 [豆包语音识别](./豆包语音识别.md)。
- **大模型**：各厂商 API Key 申请与示例见 [API 密钥与模型](./API密钥与模型.md)。

## 前端直连与鉴权

- 默认推荐同源访问：桌面端、后端静态页面，或 Vite 开发代理 `/api`、`/ws` 到后端。
- 鉴权**始终开启**，与启动方式、绑定地址无关（即使直接 `uvicorn --host 0.0.0.0`）。本机同源请求（Host 与 Origin 都是 127.0.0.1 / localhost 且端口一致）免 token；Vite 代理会去掉 `Origin`，同样免 token。
- `IA_AUTH_TOKEN` 可固定 token（否则每次启动随机生成）；`IA_AUTH_DISABLE=1` 会强制关闭鉴权，仅用于临时调试。`IA_AUTH_ENABLE` 已无作用。
- 后端默认只允许同端口 loopback origin 跨源访问。若你让单独前端地址直连后端，需要显式设置 `IA_CORS_REGEX`，例如允许本机 Vite：

```bash
IA_CORS_REGEX='^http://localhost:5173$'
```

- 非同源或局域网请求必须携带 token：HTTP 只接受 `Authorization: Bearer <token>` 请求头；WebSocket 握手使用 `?token=<token>`（访问日志会脱敏）。扫码地址把 token 放在 `#t=` 片段里，不会发到服务器。
- 如果看到浏览器 CORS 报错或接口返回 401，优先检查是否走了 Vite proxy / 同源入口；让单独前端地址直连后端时，前端拿不到 token，需要临时设置 `IA_AUTH_DISABLE=1`。

## API Key 存储

- 模型 `api_key`、豆包 / 通用 ASR 凭证和 ntfy token 默认存入系统钥匙串（Windows 凭据管理器、macOS 钥匙串、Linux Secret Service），`config.json` 中只保留 `keyring:<id>` 引用。旧版明文 `config.json` 会在下次启动时自动迁移。
- 设置 `IA_SECRET_STORE=plaintext` 可改回明文存储；已有的 `keyring:` 引用仍会被读取，并在下次保存时写回明文（也是迁回旧版本的方法）。
- 没有可用钥匙串（如无桌面环境的 Linux）时自动退回明文，并在日志中提示。

## 其他环境变量

| 变量 | 默认值 | 作用 |
| --- | --- | --- |
| `IA_LOG_RETENTION_DAYS` | `30` | `log/` 下按天轮转的日志保留天数。`interview.log` 含转写内容，可按需缩短。 |
| `IA_LOG_DIR` | `<项目>/log` | 日志目录。 |
| `IA_DATA_DIR` | `backend/data` | SQLite 数据库目录（测试或便携安装时使用）。 |
| `IA_CONFIG_PATH` | `backend/config.json` | 配置文件路径。 |
| `IA_PYTHON` | 项目 `.venv`，否则 PATH 中的 python | 桌面端启动后端所用的解释器。 |

## SOCKS 代理

如果系统设置了 `ALL_PROXY=socks5://...`，OpenAI/httpx 需要 `socksio` 才能创建客户端。项目依赖已包含该包；更新环境后执行：

```powershell
python -m pip install -r backend/requirements.txt
```

如果不使用代理，启动前清除当前终端中的代理变量即可：

```powershell
$env:ALL_PROXY = $null
$env:HTTP_PROXY = $null
$env:HTTPS_PROXY = $null
```
